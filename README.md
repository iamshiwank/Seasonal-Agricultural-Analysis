# Seasonal Agriculture Performance Analysis 🌾

## VOIS AICTE Major Project 2026–2027

This project analyzes agricultural data across **Kharif, Rabi, and Zaid seasons** to identify patterns and differences in agricultural performance, environmental conditions, resource usage, and economic outcomes.

## 🎯 Objective

To analyze how agricultural performance varies across seasons and identify meaningful patterns in environmental conditions, resource usage, crop performance, and economic outcomes.

## 📊 Dataset

- **Records:** 4,000
- **Features:** 28
- **Format:** Excel (`.xlsx`)
- **Main dimensions:** Season, crop, location, environmental conditions, agricultural inputs, yield, production, water usage, and financial performance.

## 🔎 Analysis Performed

The project includes:

- Dataset exploration and data quality checks
- Missing-value handling and data preparation
- Seasonal performance comparison
- Crop-wise yield analysis
- Irrigation/resource analysis
- Profit and economic performance analysis
- Risk analysis
- Correlation and relationship analysis
- Data visualization
- Key findings and recommendations

## 📈 Key Findings

- **Kharif** recorded the highest average yield among the three seasons.
- **Kharif** also showed the strongest average profit performance.
- **Zaid** showed comparatively lower average yield and negative average profit in the analyzed data.
- **Sugarcane** recorded the highest average yield among the crops analyzed.
- **Drip irrigation** showed the highest average yield among the irrigation methods in the dataset.

> The findings are based on the provided project dataset and should be interpreted within the scope of the available records.

3. Make sure the Excel dataset is in the same project folder.
4. Install the required libraries if needed:

```bash

```

5. Run the notebook from top to bottom.
